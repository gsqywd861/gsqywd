# 客户端计算

## 概念

客户端计算是指将媒体处理任务完全在用户浏览器中执行，而不是上传到服务器处理。

## 优势

- **隐私保护**：用户文件不会离开本地设备
- **零服务器成本**：不需要 GPU 服务器资源
- **无限并发**：每个用户独立处理，无排队等待
- **离线可用**：处理过程不需要网络连接

## 技术实现

### WebGPU

用于 AI 模型推理加速，需要 Chrome 113+、Edge 113+ 或 Firefox 120+。

### WebAssembly

用于运行 OpenCV.js 和 FFmpeg.wasm，提供接近原生的性能。

### Web Workers

用于在后台线程执行耗时处理，避免阻塞 UI。

## 降级策略

当用户设备不支持 WebGPU 时，自动切换到传统算法（OpenCV.js inpainting）。
